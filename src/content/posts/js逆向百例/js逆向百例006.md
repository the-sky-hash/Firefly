<h1>Js逆向百例：006猿人学第一题 js混淆-回溯</h1>
打开网址进来抓波观察，发现是一个get请求，需要逆向的参数在负载里面是m和q
![js逆向百例003_1.png](https://imgbed.haishuisea9.dpdns.org/file/js逆向百例/1795529431885_js逆向百例003_1.png)
从堆栈里面进来，发现没有m和q的值，向上追栈，
![js逆向百例003_2.png](https://imgbed.haishuisea9.dpdns.org/file/js逆向百例/1795529690711_js逆向百例003_2.png)
来到这里发现m和q的踪迹，来自

```js 
var d={"page":p,"m":r(t,window.o),"q":window.i+= window.o +'-'+ t +"|"}
```
在这里下断点，追进去
![js逆向百例003_3.png](https://imgbed.haishuisea9.dpdns.org/file/js逆向百例/1795529687001_js逆向百例003_3.png)
再往下追，来到如图所示的位置
![js逆向百例003_4.png](https://imgbed.haishuisea9.dpdns.org/file/js逆向百例/1795529687775_js逆向百例003_4.png)
看到这个是个webpack,一个大的自执行函数，把整个代码全扣下来，放到本地进行补环境，
上面有一段混淆，直接丢给ai分析，解混淆出来就是window.o=1，直接把它替换掉，
第二个点是window未定义，直接补上window=globalThis;
再然后遇见一个"Message too long for RSA"，这个一看就就是干扰项，直接把假分支干掉，
再然后还是出不来m的值，启动node本地调试，发现来到一处大混淆位置，去浏览器器查找该位置，在此处下断点，
![js逆向百例003_5.png](https://imgbed.haishuisea9.dpdns.org/file/js逆向百例/1795529685402_js逆向百例003_5.png)
刷新页面断在这里，把一大段混淆在控制台执行，发现是false,直接本地替换掉，就出值了，剩下就是发请求的事情了，发送请求时如果使用execjs会遇见编码问题
```py
import subprocess
from functools import partial
subprocess.Popen = partial(subprocess.Popen, encoding="utf-8")
import os
```
用这个就可以解决，但得放在import execjs的前面
